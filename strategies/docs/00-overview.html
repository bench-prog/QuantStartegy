快速切换策略回测

修改 run_backtest.py 中的导入和配置即可切换策略：

# 示例：切换到布林带回归策略
from strategies.mean_reversion.bollinger_reversion import BollingerReversion, BollingerReversionConfig

STRATEGY_CLS = BollingerReversion
CONFIG_CLS   = BollingerReversionConfig
STRATEGY_PARAMS = {
    "period": 20,
    "std_dev": Decimal("2.0"),
    "trade_size": Decimal("100000"),
}
实盘接入：参考 run_live.py 中的 Binance 网关配置注释，填入 API Key 即可对接 Binance 现货/合约实盘。适配器已封装 K 线、深度、成交、24h 统计、资金费率、持仓量等数据源。
